# 混合输入识别约定

`parseDocument` 是 document 模式的唯一域边界入口。编辑器、本地 API 与核心转换使用同一套节点，保存原文、原始 UTF-16 半开区间和诊断，不插入公式定界符、不整体规范化文本。

## 显式定界符

支持实际字符 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`。单行或跨一个换行都可以；空内容可用 `\(\)`、`\[\]`、`$$$$`。既有最长开符规则保留：`$$` 是 display 开符，不表示空 inline。两个相邻公式可以直接相接。

反斜杠按奇偶转义，`\$` 表示字面美元。不会自动把粘贴的双反斜杠变成单反斜杠；矩阵 `\\` 换行与 UNC 路径原样保存。JSON 请求应由 JSON 编解码器处理转义。

美元定界符优先。`$5 and $10`、未闭合的 `$5` 同时提示可能是金额，不擅自重写成货币；完整 `$5$` 仍为公式。金额应写 `\$5`。

## 有界自动识别

- 完整 `\frac`、`\dfrac`、`\tfrac`、`\sqrt` 是强起点；支持花括号参数，以及 TeX 的单 token 参数，如 `\frac12`、`\sqrt x`。
- 完整 `\ce{...}` 是独立 chemistry 节点。单个 `C` 不会猜为化学元素。
- 完整受支持环境（matrix、pmatrix、bmatrix、Bmatrix、vmatrix、Vmatrix、cases、aligned）可跨行；嵌套、行分隔符及原文均保留，后续仍由现有数学解析器核验。
- 完整且名称精确匹配的希腊字母命令（如 `\alpha`、`\alpha\beta`）本身就是数学原子。现有数学解析器认识的函数、样式、重音及符号在有操作数/脚标/运算结构时扩展，如 `\sin^2 x`、`\mathbf{x}+1`、`\alpha+\beta`、`x\leq 1`。
- 已有符号表中的独立常量 `\infty`、`\emptyset`、`\varnothing`、`\aleph`（及表中已有的 `∞`、`∅` 别名）直接作为数学操作数；不误作需要右侧操作数的中缀运算符。乘号/关系符等中缀符号需要两侧操作数；求和/积分等前缀、修饰符和定界符仍须明确上下文，孤立输入给出提示，必要时选显式模式。未新增 TeX 命令或点位表。
- 括号组从内部传播完整数学证据，如 `(x=1)`、`(\frac{1}{2})`、`(\alpha)` 及嵌套形式。只有弱内容的 `(x)` 保留正文；`(x+1)` 等仍有多义性的弱表达式、缺少操作数的 `(x=)` 或混入不明确英文的 `(\alpha hello)` 保留可见提示，不报告完整转换。组可被外侧关系式进一步确定，例如 `(x+1)=2`。
- 合法脚标或明确关系式可以成为数学域，如 `x^2+1`、`a+b=c`、`x=1`。明确相邻的单字母、数字、数学括号组及希腊字母原子支持隐式相乘，如 `\frac{1}{2}x`、`x^2y`、`2x^2`。完整原子、脚标、运算符和后续原子连续构成一个公式区段，`前\frac{1}{2}+\sqrt{3}后` 的中间部分是一个节点。
- 顶层汉字、中文标点、普通英文和换行结束裸公式。完整花括号参数、text/mbox、化学条件内部可以保留汉字、空格和单个换行。
- 只从安全词法边界尝试。英文词、数字本身、`foo_bar`、URL、Windows drive/UNC 路径不自动变成公式；这不承诺所有路径字符已有盲文规则，原始字符仍可能产生可见的未支持提示。

`a+b`、缺少参数、未知宏（例如 `\fraction`）及不清晰边界保留源区间并提示，不能把诊断结果视为完整转换。末尾运算符缺少可识别操作数时，前面的完整公式仍转换，后续文本保留并报告不完整表达式；`x=`、`x=hello` 也会保留覆盖运算符的不确定提示，不报告完整转换。强公式紧贴普通英文词（如 `x^2hello`）时，英文不拆成变量串，保留英文尾文并提示边界不确定；分开的普通英文和顶层中文按正文边界处理。不是完整 TeX 语言识别器，不自动猜任意代码或自然语言的数学意图；明确意图可使用定界符或 math/chemistry/physics 模式。显式模式关闭裸式猜测诊断，但保留选定域的实际不支持/格式错误诊断。

## 恢复、映射与中文

空白行（含 CRLF、空格和 tab）为恢复边界。显式公式、裸参数及环境不会跨该边界搜索匹配结束符；因此跨空白段落的公式应拆分。无法分类的普通外层括号只推进开括号并交还文档扫描，后面的四类显式公式、已知裸命令和尾文继续独立识别。合法 `\text`、`\ce` 及其他已确认结构的平衡参数保持其内部原文，不全局搜索并拆开参数。合法长弱组仍整体保留，候选递归预算保持不变。坏公式不能吞掉后面段落；未知宏诊断覆盖完整宏名，后面的已知命令和中文继续处理。未知/坏宏使用 `unparsed`，原文始终保留，转换显示未处理占位及不完整状态。`a+b` 这类弱表达式保持 prose 节点和既有符号提及编码，同时附不确定提示，不假定它已成为数学域。

文档长度上限仍为 100000 UTF-16 单元；分组/环境结束位置先索引，候选递归限制 64，数学域解析继续使用其长度和深度预算。大量坏开符不会每次重新扫描到文末。

新节点 `bare-math` / `chemistry` 的 `raw`、`content` 和两组 span 都指向同一原始区段。四类显式定界符节点接口不变。纯公式不添加行内夹文标记；夹文数学用现有数学起始规则，化学依其独立规则关闭。没有新增标准点位表。

裸汉字在 TeX 脚标绑定之后才合并为连续中文分析域，`x^中文` 的上标仍只有“中”，`中文^2` 的脚标仍属于“文”。不跨空白、包装、组或脚标合并。人工合词、拆词、读音覆盖使用全局原文区间；跨真正结构边界的覆盖明确报错。宽度重排复用已编码中文分析。时间/标点消歧只在真正的 prose 节点内扩写，不因同一段中有化学而错误拒绝，也不跨进公式内部扩写。API 决策、人工优先和超时/离线回退语义不变。
