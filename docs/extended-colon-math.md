# 时间、比例与限定数学结构（2026-09-26）

本轮仅支持下面明确的语义和解析范围。默认保留原文source；时长/时刻的时分秒文字是透明的语义展开，不是声称国家标准定义了HH:MM(:SS)专用盲文符号。

## 输入与优先级

- 时刻：H:MM、HH:MM、H:MM:SS、HH:MM:SS，支持全角冒号。小时0–23，分钟/秒两位00–59；不接受24:00、分数秒或四字段链。
- 时长：候选duration明确表示小时:分钟[:秒]（小时最多6位）；候选duration-ms明确表示分钟:秒。三字段明确时长可自动采用；两字段只有“时分”或“分秒”单位上下文才采用对应解释。“耗时12:30”保留待确认，不能把实现约定当成已知的用户语义。
- ratio：完整的带符号整数/小数比及连比，例如3.5:-2:1。ASCII正负号、Unicode负号、全角冒号均保留绝对原文位置。格式不全、相邻额外小数点或冒号不进行部分替换。当前不接受科学计数、空格分隔比例、符号量比或任意数量单位。
- 每条连续数字冒号链只创建首冒号的一项决策，tokenSpan覆盖整个链。人工选择优先；不确定模型结果继续待确认。明确preserve策略不会展开时刻或时长。
- 文字展开末尾单位是原文结束位置的零宽插入；其余单位对应原冒号位置。完整时间和比例采用同一原子组，过窄行宽不得硬切。

## 数学新增范围

- 映射：只识别整个数学sequence恰为“单ASCII拉丁字母 : 单ASCII拉丁字母 → 单ASCII拉丁字母”的五节点形式，支持→、\\to、\\rightarrow。以f:A→B为例；集合表达式、脚标、多个函数名、Type注解均未扩展。默认AST识别遵循该限定；编辑器决策中的manual unknown显式阻止采用，并保留未解决诊断；manual ratio仍优先。
- gathered：仅作每行一个表达式的线性多行输入适配，沿用现有aligned的行分隔与两方续行缩进机制；不保持TeX视觉居中。含&列对齐时诊断不支持；嵌套/组合矩阵仍保持原有限制。
- 已有数学负号/减号与斜分式规则补回归；没有将普通文件路径、日期或词内连字符自动当成数学。slash/minus全局消歧仍非通用功能。
