# 数学式：先结构，后点位

依据：[GB/T 18028—2010 官方标准页](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=7540BACDF4C6BAB8C9F8618D129D55EB)，第 5–6 章；尤其 §5.1 数字、§5.4 换行、§6.1 运算符、§6.6 上下标。应查官方原页，勿照搬其他数学盲文体系。

1. 解析变量、数字、括号、运算符、分数、根式、上下标以及 `\text{…}` 等文本区段；未知宏或不完整式子保留原文并标记未完成。
2. 根据字母大小写及数学领域写字母标记。数字、指数数字、化学原子个数并非同一规则；不跨域共享一个“数字模板”。
3. 二次幂示例：`a²` 为 `⠰⠁⠌⠆`；`⠌` 是上指数起始符，简单整数指数 2 可用降点位 `⠆`，按 §6.6 的省略条件不加多余数号或结束符。
4. `+` 是点 235 `⠖`，`=` 是点 2356 `⠶`。§6.1.2.1 对这里的运算符要求**前空一方**，后面不再空一方；因此 `a²+b²=c²` 的局部串为 `⠰⠁⠌⠆⠀⠖⠰⠃⠌⠆⠀⠶⠰⠉⠌⠆`。比号、乘点等另有两侧不空方的例外，不能把“前空一方”扩成所有符号通则。
5. 公式嵌入正文时核对领域标记、相邻中文和标点。先定公式边界，再排版；行宽不够时只在该领域允许的断点换行，并补所需续写/恢复标记。

检查列表：原文 TeX 是否闭合、数学 AST 是否完整、每个符号的标准章节、运算符两侧方数、数字状态、公式与正文切换、断行前后可逆性。不要把软件能解析的一小部分 LaTeX 说成“支持所有 LaTeX”。
