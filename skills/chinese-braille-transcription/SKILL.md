# 中文、数学、化学盲文转写

把原文变成可追溯的盲文文档，而不是凭相似字符猜一串盲文。本 skill 依据《国家通用盲文方案》GF 0019—2018、《中国盲文数学、物理、化学符号》GB/T 18028—2010；出版排版另参考 GB/T 44725—2024。标准版本和原文、采用的模式、行宽、段首缩进必须随结果说明。**本 skill 不是全条款符合性认证；没有核实的符号不得编造点位。**

## 转写流程

1. 保留完整原文及每段的起止位置。先按语义划分中文、普通外文、数学式和化学式，再决定读音、词界和冒号等歧义。`$…$`、`$$…$$`、`\(…\)`、`\[…\]` 明确表示数学；`\ce{…}` 明确表示化学。未闭合定界符、不支持的 TeX/mhchem 不能当作已正确翻译。
2. 中文逐字确定拼音与声调，再按 GF 0019 的词语连写/分写规则决定**词界**；通用分词器只提供建议。多音字、专名、时间/比例冒号须结合上下文判断，仍有歧义时列出候选，不要虚构确定性。详见 [中文规则](references/chinese.md)。
3. 在各领域内部先编码成盲文方及标记，再处理中文与公式的切换。数学、化学各有独立的字母、数字、上下标和运算符规则；同一个 `⠖` 在不同上下文不能凭外形解释。详见 [数学规则](references/math.md)、[化学规则](references/chemistry.md)。
4. **最后**按指定行宽、段落和合法断点排版。逐行数盲文方；`⠀`（U+2800）是一方，普通 ASCII 空格不应混入 Unicode 盲文正文。词内跨行只在完整音节后使用续写规则；绝不为了凑满一行把符号或音节随意切开。详见 [空方、换行与核验](references/layout-and-verification.md)。
5. 对照原文逐段输出：Unicode 盲文、原文→盲文片段、歧义/未支持项、规则出处及排版参数。区分“已按具体条款核实”“算法建议”和“尚待盲文校对者确认”。若使用转换器，检查其 `complete`、诊断和原文区间映射；不能只复制 `unicode` 字符串。

## 可靠性边界

- 优先查标准原文及其例子；对照另一模型或旧版盲文时先确认是否为**同一盲文体系**。解释看似合理不等于点位正确。
- 无法核对的化学反应号、复杂分式/矩阵、结构式、图形、物理专用符号或任意 LaTeX，应标注未完成；不要用别国体系的近似符号冒充 GB/T 18028。
- 一次模型判断可以提出词界或读音，但标准点位和排版禁则仍需独立检查。不要把“没有待校对项”解释为“整段已通过国标认证”。
- 本 skill 不请求或传输 API 密钥，不依赖 SimpleTex 私有服务。若环境提供可信的盲文转换工具，可用它产生候选，再按本 skill 核验；没有工具时仅转写自己能逐项核实的范围。

## 快速对照

下列**局部**例子已经对照 GB/T 18028—2010，`⠀` 表示一方：

| 原文 | 盲文局部 | 核对点 |
|---|---|---|
| `a²+b²=c²` | `⠰⠁⠌⠆⠀⠖⠰⠃⠌⠆⠀⠶⠰⠉⠌⠆` | 加号和等号前空一方，后不空；整数上标 2 用降点位 |
| `2H₂+O₂→2H₂O` | `⠼⠃⠠⠓⠆⠀⠖⠠⠕⠆⠀⠒⠕⠼⠃⠸⠓⠆⠕` | 化学原子个数直接用降点位；向右反应号是两方 `⠒⠕` |

这些是公式内部的局部编码；嵌入中文叙述还要依相应领域的起止标记与空方规则处理。不要把这两行机械套用于所有数学或化学输入。
